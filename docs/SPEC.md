# v1 仕様: LINEスタンプ一括コンバーター

## プロダクト原則
- **ファイルは絶対にサーバーへ送らない**(全処理ブラウザ内)。これは技術選択ではなくプロダクトの売り文句であり責任設計
- 出力は機械的変換のみ。助言・判断・審査結果の保証は出力しない(免責明記)
- サイト名は仮(`src/lib/site.ts` で一元管理、後で差し替え)

## 根拠とする規格(LINE Creators Market 公式ガイドライン, 2026-06確認)
| 画像 | サイズ | 個数 |
|---|---|---|
| スタンプ画像 | W370×H320px 以内 | 8/16/24/32/40 |
| メイン画像 main.png | W240×H240px | 1 |
| タブ画像 tab.png | W96×H74px | 1 |

共通: PNG・透過必須・縦横偶数px・各1MB以下・ZIP60MB以下・解像度72dpi以上・RGB・コンテンツ外周に約10pxの余白推奨

## v1 機能(これ以外作らない)
1. **一括変換**: 最大40枚をドラッグ&ドロップ(PNG/JPG/WebP受付)
   - 余白10pxを確保した350×300の内接領域にアスペクト比維持で縮小 → 370×320以内・偶数pxのキャンバスに配置 → 透過PNG出力
   - JPG入力は背景透過にならない旨を警告(自動切り抜きはしない)
2. **メイン/タブ生成**: 一覧から1枚選択 → main.png(240×240)とtab.png(96×74)を同ロジックで生成
3. **審査前チェック**: 変換後の各ファイルに対し 偶数px / 1MB以下 / 透過有無 / 個数(8,16,24,32,40のいずれか) を判定して一覧表示。NG項目は理由つき
4. **ZIP出力**: main.png, tab.png, 01.png〜NN.png の規定ファイル名で一括ダウンロード
5. **SEOコンテンツ**: 同ページ下部に規格早見表・よくある審査落ち理由(検索流入の受け皿)

## v1 でやらないこと
課金・アカウント・AI機能・背景除去・絵文字/着せかえ対応(v1.1候補)・アニメーションスタンプ

## 技術
- Next.js (App Router, TypeScript, Tailwind) + Vercel無料枠
- 画像処理: Canvas API / ZIP: fflate / 外部API・DBなし
- 計測: Vercel Analytics + Google Search Console(ドメイン取得後)

## ローンチ手順(コード完成後)
1. ドメイン取得 → Vercel接続 → GSC登録 → sitemap送信
2. AdSense審査申請(コンテンツページが必要なため規格解説を充実させてから)
3. X投稿(制作界隈向け)で初動トラフィック
