# earth-trend の意義

> 2026-06-13 確定。市場調査と冷静な判断を経て言語化した、このプロダクトの背骨。
> 機能や実装で迷ったら、ここに照らして決める。

## これは何か

earth-trend は「トレンドツール」ではない。

検索クエリは、人類が最も正直に「知りたい」を吐き出している記録である(人は口に出さないことも検索する)。
だから扱っている本体は **「今、世界が何に意識を向け、その意識がどう繋がっているか」= 集合的注意(collective attention)の構造** である。トレンドはその入口にすぎない。

一言で言えば:

> **人類の意識の、生きた地図。**
> 時計が時刻を、気圧計が天候を映すように、「今、世界が何を不思議に思っているか」を映す文化的計器。

## 原体験(なぜ作ったか)

このプロジェクトは、機能よりも先に「思想」から始まった。

- いまのSNSや検索は **パーソナライズされすぎて、自分の鏡しか映さない**(エコーチェンバー)。
- かといって Google トレンドは **無機質な表でしかない**(感情も流れも見えない)。
- その間を埋めたい——**世界の人々の関心の流れを、もっと楽しく、違う角度から眺める**。
- そして **「データの見せ方そのもの」への挑戦**。同じ事実でも、表現が変われば意味の感じ方が変わる。

行動分析学的に言えば、人の検索ログは「言葉にしない本音(private events)が観測可能な行動として漏れたもの」。
それを **集団スケールで・美しく・新しい表現で** 見せることが、このサイトの遊びであり実験である。
これからも「何のためのサイトか」を問い直しながら、意義に照らして更新を続ける。

## 3つの高度(同じデータを別の視点で見る)

- **リスト = 読む / 静**: 世界の「今日の脈拍」を落ち着いて一覧する。習慣の surface。(現在の実装ではホーム=世界一覧と国ページがこの高度)
- **地球儀 = 感じる / 俯瞰**: 世界規模で情緒的に眺める。シェアの顔。
- **グラフ = 潜る / 動**: 一点から繋がりを無限に辿る。魂。

機能の寄せ集めではなく、集合意識を「読む・感じる・潜る」3つの高度。

## 「つながり」の4次元(追求の対象)

1. **連想** (今のサジェスト): 一つの好奇心が次に何を欲するか。一人の心の連想の網
2. **共起**: 同時に燃えるトレンド = 同じ現実が別の角度から見られている
3. **文化**: 国を跨ぐ同一トピック = 世界が同じものを違うレンズで見ている
4. **時間**: 物語が展開するにつれ関係が変わる(蓄積が要る)

今あるのは 1 だけ。伸びしろは 2,3,4 を同じグラフ上で辿れるようにすること。

## 何のゲームを戦っているか(冷静な判断)

市場調査の結論:
- **事業(収益)としては弱い**。「データ探索を destination に」は The Pudding ですら単体では食えず、受託スタジオで支えている。実用を足せば稼げるが、それは競合の退屈な土俵に戻り魂を殺す。
- **アテンション/craft/ブランドのゲームとしては強い**。この genre(Listen to Wikipedia, Pudding, Windy)は文化的注目・受賞・キャリアを定義する portfolio を再現性高く生む。

→ オーナーの目的関数(面白ければ嬉しい・金は要らない・1年やれる・side project・コストもゼロにしたい)と完全一致。
**よってアテンションと craft の旗で勝負する。収益は目的にしない。**

## 一発屋を超える鍵

オープンエンドな探索トイの宿命 =「わお30秒→離脱→戻らない」。
解は「戻る理由 = 更新され続けること」。
**集合的注意は二度と同じ形にならない = データが本質的に毎日新しい。** これが実用を足さず native に成立する唯一の return loop。
- グラフ(つながり) = わお・獲得・シェアされる魂(花火)
- リスト(今日の脈拍) = 戻る理由・習慣(retention エンジン)
- 蓄積(時間) = 織物が日々どう変形するかを見せ、両者を深める

## 「ライブ」の設計判断(自動更新をどこに置くか)

「戻る理由＝更新され続ける」を混同しない。2つは別物:
- **A. 再訪の理由**: 次に来た時に中身が違う。→ 既に成立(30分ごとスナップショット・訪問のたび新鮮)。retention の本体はこれ。
- **B. 開きっぱで変わる(live-while-open)**: アンビエントな世界ティッカー。別の体験。

**ビューの性質で出し分ける**:
- 読む系(リスト/国別) = 静。開きっぱにしない。**全体自動更新は罠**(30分待って微変化=無価値 / 全タブのポーリングでコスト増 / 画面が動く)。→ 入れない。
- アンビエント系(地球儀) = 開きっぱで眺める。**自動更新する**(済: 30分ポーリング=snapshot間隔に一致)。
- 「開きっぱ体験」を強化するなら、器はリストでなく**アンビューを増やす**(将来: マーキーの全画面ティッカー化など)。

**読む系で今やるのは「ライブ感を安く・正直に伝える」だけ**: 相対更新時刻(X分前)＋ live ドット。
自動更新本体(トースト通知 等)は **GA で「読む系を開きっぱにする人がいるか(滞在時間)」を見てから判断**(データ駆動)。

## 制約(不変条件)

1. **コストゼロ**: 無料データソース + 無料枠のみ。外部API課金なし(AI機能は無料枠20/日で不成立のため撤去済み)
2. **放置で回る**: 運用稼働ほぼゼロ。営業なし
3. **魂を売らない**: 実用機能を足してマーケターSaaS化しない。データ深度で競合に張り合わない

## やらないこと(anti-goals)

- マーケター向け有料ダッシュボード化
- 競合(Exploding Topics / Glimpse)とのデータ深度競争
- 収益のための実用機能の後付けでビジョンを濁すこと

## データ表現の探索(拡張の方向)

「データの見せ方への挑戦」が原体験なので、**新しい表現の追加**はこのプロジェクトの本筋。
ただし闇雲に増やさず、各案を3つの軸で評価する:

1. **意義(集合的注意)**: 個人でなく「世界の集合的な関心/行動」を映すか。哲学・行動分析の観点で語れるか。
2. **コストゼロ・放置で回る**: 無料データ源 + 無料枠で、運用稼働ほぼゼロで成立するか。
3. **SEO/拡散**: クロール可能なテキストの土台があるか(rankableか) / シェアされる絵になるか。

### 候補(温める)
- **横方向の文字垂れ流し(マーキー)**: 現トップhero背景。実トレンド語が流れる=「世界の今」を体感。表現として面白く、低コスト。→ 独立した1ビュー化や、速度/密度で「勢い」を表す余地。
- **株価/指数のヒートマップ**: 市場の集合的関心。色=騰落、面積=規模。データ源の無料枠と利用規約の確認が前提。
- **運行情報マップ(飛行機/交通)風**: 「世界が物理的に動いている」可視化。集合的行動の別レイヤー。データ源のコストが課題。
- **多様なグラフ(時系列・共起・相関 等)**: PHILOSOPHYの「つながりの4次元(連想/共起/文化/時間)」を別の幾何で見せる。

判断は常に「魂を売らない(マーケSaaS化しない)」「コストゼロ」に照らす。実用機能の後付けでビジョンを濁さない。
